A dashboard number: uppercase caps label, 3xl figure, one muted footnote. Lay them out in a `grid grid-cols-2 md:grid-cols-3 lg:grid-cols-6 gap-4`. Use an em dash for "nothing yet", never a zero that lies.

```tsx
<StatTile label="Replied" value="14" sub="7.1% of sent" />
```
