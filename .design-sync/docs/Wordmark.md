The wordmark is the logo: the app name in lowercase Source Serif 4, with the trailing period in gold. That period is the one gold element allowed on a page, so nothing else on the page uses `text-accent`.

Use `className` for size only: `text-xl` in the top bar, `text-3xl` above a login card, `text-5xl` on a landing page.

```tsx
<Wordmark className="text-xl" />
```
